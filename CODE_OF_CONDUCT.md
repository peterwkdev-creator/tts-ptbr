# Código de conduta

Vale nas issues, nos pull requests e em qualquer espaço do projeto.

- Trate todo mundo com respeito, seja qual for a experiência, a profissão
  ou a opinião de cada um.
- Critique o código e o argumento, nunca a pessoa.
- Nada de assédio, ofensa, discriminação, nem exposição de dado pessoal de
  alguém.
- Não publique dado real de pessoa ou de empresa: use textos inventados.
- Divergência sobre pronúncia se resolve pela medida (WER do `medir.py`) e
  pela escuta da mesma frase, não pela opinião.

Quem mantém o projeto pode editar ou apagar comentário, fechar issue ou pull
request e bloquear quem descumprir estas regras. Para relatar um problema,
use o "Report content" do GitHub, no menu do comentário ou da issue.
