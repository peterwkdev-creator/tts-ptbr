# Histórico de versões

Cada versão tem uma tag `vX.Y.Z` no commit que a publicou. A versão do
método de narração (por exemplo `r10 5-final`) sai no `tempos.json` de cada
narração.

## 0.1.0 — 18/10/2026

- Primeira versão pública: normalizador PT-BR com dicionário de pronúncia,
  narração frase a frase com o Kokoro-82M, acabamento a -16 LUFS e medida
  pelo Whisper (WER e vãos), mais os scripts das rodadas de calibração.
